# Desktop / DMG

Финальный артефакт для macOS — `.dmg` с приложением, которое поднимает
локальный backend на `127.0.0.1` и открывает тот же UI.

## Имя и идентификаторы

| Что | Значение |
|---|---|
| Отображаемое имя | `PDF2Text` |
| Bundle identifier | `com.<владелец>.pdf2text` |
| Файл образа | `PDF2Text-<версия>.dmg` |
| Иконка | `icons/AppIcon.icns` |

Регистр — `PDF2Text`, не `PDF2TEXT`: в `DESIGN.md` записано «регистр
предложения везде». Имя репозитория остаётся `local_OCR`.

## Иконка

```bash
python desktop/make_icon.py
iconutil -c icns desktop/icons/AppIcon.iconset -o desktop/icons/AppIcon.icns
```

`iconutil` не работает под песочницей Claude Code — падает с
`Failed to generate ICNS` даже на корректном наборе. Запускать напрямую.

## Целевой путь

1. Сейчас: веб-MVP (`python -m backend.main` или `local-ocr`).
2. Затем: Tauri 2 обёртка в `desktop/`.
3. Сборка: `npm run tauri build` → `*.dmg`.

Приложение не должно ходить в сеть. Backend остаётся тем же FastAPI.

## Подпись и Gatekeeper

Три уровня, и разница видна пользователю, а не разработчику.

| Уровень | Цена | Что видит человек, скачавший `.dmg` |
|---|---|---|
| Без подписи | 0 ₽ | «macOS не удалось проверить, нет ли вредоносного ПО». Открыть можно только через Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть» |
| Developer ID, без нотаризации | $99/год | То же предупреждение. Подпись без нотаризации Gatekeeper не устраивает |
| Developer ID + нотаризация | $99/год | Обычный запуск по двойному клику |

**Важно про macOS 15.** Старый обход — Control-click по приложению → «Открыть» — Apple убрал
в Sequoia. Раньше это был один клик, теперь путь через Системные настройки. Инструкции из
интернета, написанные до 2024 года, показывают неработающий способ.

Что **не** помогает:

- ad-hoc подпись (`codesign -s -`) — приложение запустится на машине сборки, у скачавшего нет;
- бесплатный сертификат по Apple ID из Xcode — только для разработки, нотаризовать им нельзя;
- `xattr -d com.apple.quarantine` — работает, но требует терминала, то есть проваливает
  критерий готовности;
- Homebrew cask — по умолчанию тоже ставит карантин.

Каналы, где Gatekeeper не участвует вообще: `pip install`, `uvx`, запуск локального UI
на `127.0.0.1`. MCP-сервер распространяется именно так и подписи не требует.

$99 — решение коммерческое, не техническое. Пока продаж нет, неподписанный DMG допустим.

## Почему не сразу DMG

Сначала нужен стабильный локальный путь «файл → triage → результат».
Tauri только упаковывает уже работающий UI/API.
